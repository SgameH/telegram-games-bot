# 🎮 Telegram Multiplayer Games Bot

بوت تيليجرام تفاعلي وجماعي يضم مجموعة ممتعة من الألعاب المصغرة التي يمكن لعبها ومشاركتها مع الأصدقاء عبر روابط التحدي المباشرة ونظام البحث السريع (Inline)، مع نظام حماية اشتراك إجباري في القنوات.

---

## 🕹️ الألعاب المتاحة في البوت

1. **❌ لعبة اكس أو (Tic Tac Toe):** اللعبة الكلاسيكية الشهيرة لتحديد الفائز عبر ترتيب 3 رموز متتالية.
2. **✊ حجر - ورقة - مقص (Rock Paper Scissors):** المواجهة السريعة لاختبار الحظ.
3. **🏴‍☠️ جزيرة الكنوز والأموال (Treasure):** مغامرة استكشاف للتنقيب عن الكنوز المخفية وجمع النقاط (مع تحديد 3 صناديق فارغة بدقة وتوزيع باقي الكنوز عشوائياً).
4. **💣 الصناديق المفخخة (Traps):** اختبار ذكاء وحظ لتجنب الفخاخ.
5. **⚓ السفن الحربية (Battleship):** معركة بحرية استراتيجية لإغراق أسطول الخصم.

---

## ✨ المميزات الرئيسية

* **دعم اللعب المباشر (Inline Mode):** إرسال الألعاب والبدء بالمناقشة والتحدي مباشرة داخل أي محادثة أو مجموعة عبر كتابة يوزر البوت مع أيقونات مخصصة لكل لعبة.
* **روابط التحدي (Deep Linking):** إمكانية إنشاء رابط تحدي خاص لكل لعبة ومشاركته مع الأصدقاء.
* **نظام الاشتراك الإجباري:** حماية البوت بحيث لا يعمل إلا بعد اشتراك المستخدم في القناة الرسمية.
* **واجهات تفاعلية:** أزرار شفافة (Inline Keyboards) لسهولة وسلاسة التنقل واللعب.

---

## 🛠️ متطلبات التشغيل

* Python 3.9+
* مكتبة `python-telegram-bot`

---

## 🚀 كيفية التثبيت والاستضافة

1. قم بعمل Fork أو Clone لهذا المستودع.
2. أضف ملفات الألعاب وملف `main.py`.
3. على منصة الاستضافة (مثل Render أو Railway)، أنشئ مشروعاً جديداً.
4. أضف متغير البيئة التالي في إعدادات المنصة:
   * **Key:** `TOKEN`
   * **Value:** توكن البوت الخاص بك من BotFather.
5. استمتع بتشغيل البوت!
